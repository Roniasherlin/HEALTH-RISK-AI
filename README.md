❤️ HealthRisk AI

ML Risk Prediction & Explainable AI Application

HealthRisk AI is an end-to-end machine learning application that predicts heart-disease risk from patient health indicators and explains the model's prediction using Explainable AI (SHAP).

The project demonstrates the complete machine learning workflow — from data preprocessing and model training to evaluation, explainability, and deployment through a Streamlit interface.

🎯 Project Objective

The objective of this project is to build an interpretable machine learning system that can:

1. Process and preprocess healthcare data
2. Predict heart-disease risk using machine learning
3. Compare multiple classification models
4. Tune the best-performing model
5.Evaluate model performance using multiple metrics
6.Explain individual predictions using SHAP
7.Provide an interactive prediction interface using Streamlit

Disclaimer:This project is intended for educational and demonstration purposes only. It is not a medical diagnostic tool.
